Ayuda, publicación y créditos

Para padres: llenar y enviar la boleta. Para la escuela: publicar la app y administrar los registros.

Cómo usa la app el padre de familia
  1. Abra Nueva boleta / Registro y complete la boleta igual que el formato físico.
  2. Escriba su correo, marque la autorización de datos y pulse Enviar matrícula.
  3. Recibirá en pantalla (y en su correo, si lo marcó) el folio MAT-2027-###.
  4. La escuela es notificada por correo automáticamente con el detalle de la nueva matrícula.
Publicación en línea (una sola vez)
  1. Abra el archivo Codigo Apps Script - Registro Matricula 2027.gs: ahí están los 6 pasos de instalación (hoja de cálculo Google, función INSTALAR, implementación como app web y la URL /exec).
  2. Pegue esa URL en este HTML, en la línea CONFIG.urlAppsScript — o bien, más fácil: entre al Área administrativa ▸ Instalación asistida, péguela ahí y pulse Verificar y guardar (la app la guarda y la verifica sola; con Copiar línea para el HTML obtiene la línea lista para pegarla en el archivo).
  3. Paso 0 automático: en Instalación asistida seleccione la carpeta de publicación (la carpeta «Publicar en GitHub Pages»): al verificar la URL, el README.md (Paso 0) y el index.html de esa carpeta se actualizan solos con la URL, listos para subir a GitHub (Chrome/Edge).
  4. Suba este HTML a su página (Drive web, GitHub Pages, hosting institucional, etc.). Los padres entran a esa dirección.
  5. Los registros caen en la hoja MATRICULA2027 de Google; se descarga como Excel desde Archivo > Descargar > .xlsx, o desde el panel con Exportar a Excel.
  6. Si la URL no está configurada, la app funciona en modo local: guarda en este mismo archivo/equipo y avisa en el panel.
Área administrativa

Botón Área administrativa: abre una ventana aparte protegida con usuario y contraseña (o con la contraseña maestra, CONFIG.claveAdmin, dejando el usuario vacío). Allí el administrador puede:

  • Ver todos los registros (en línea y locales), buscar y filtrar por estado o modalidad.
  • Administradores: agregar o quitar personas con acceso y cambiar contraseñas (se guardan cifradas, en SHA-256; el texto original no se almacena).
  • Apariencia y colores: cambiar el fondo del encabezado y de las secciones entre 4 temas (azul, verde, turquesa, vino) y compartirlos con todos los equipos.
  • Instalación asistida: pegar el sitio de guardado (URL /exec), que la app verifique la conexión, le diga qué falta y le deje copiar el código .gs en un clic.
  • Cambiar el estado: Recibida, En revisión, Aprobada, Observada o Anulada.
  • Descargar el Excel (50 columnas, con filtros), CSV o respaldo JSON.
  • Definir los correos de notificación que reciben el aviso de nueva matrícula.
  • Carpeta Excel: elegir la carpeta de este equipo donde se guardará y actualizará automáticamente MATRICULA_2027.xlsx con el mismo formato de la exportación (Chrome/Edge; funciona también en la página publicada).
Puente local: Excel en una ruta + Outlook

Para que cada Enviar matrícula quede automática y directamente en un archivo Excel de la escuela y la escuela reciba el aviso por Microsoft Outlook, use el puente local:

  1. En la PC con Excel y Outlook, ejecute «Iniciar puente matricula.bat» y déjelo abierto (para arrancarlo con Windows: Win+R ▸ shell:startup y copie ahí el acceso directo).
  2. Área administrativa ▸ Excel y Outlook: pegue el token del puente, escriba la ruta del archivo Excel (por ejemplo C:\Escuela\MATRICULA_2027.xlsx o una carpeta de red \\servidor\…) y pulse Guardar en el puente.
  3. En Correos de notificación defina los destinatarios (usuarios asignados por el administrador); se sincronizan con el puente al guardar.
  4. Al enviar una boleta: la fila se agrega al Excel (se crea con las 50 columnas si no existe) y Outlook envía el aviso de nueva matrícula. El panel muestra el resultado (ruta y destinatarios).

Nota: el puente solo funciona en la PC donde corre el script. Las boletas que otras familias envíen desde internet (con la URL de Google Apps Script) quedan en la hoja de Google y se descargan como Excel desde el panel; el puente atiende los envíos hechos en la propia escuela.

Carpeta de guardado · Excel con todos los registros

El administrador elige una carpeta de este equipo: allí se guardará y se actualizará el archivo MATRICULA_2027.xlsx con el mismo formato de la exportación (las mismas 50 columnas y la hoja de información). La página puede estar publicada en internet: la carpeta es la de este equipo y solo este navegador puede escribir en ella.

Requiere Google Chrome o Microsoft Edge (los navegadores que permiten elegir carpetas) y que la página esté en HTTPS o abierta desde este equipo.

⚠ Atención: el archivo se reescribe por completo con los registros que conoce este navegador. Si otras vías (puente local, otro equipo) agregan filas al mismo archivo, esas filas podrían perderse en la siguiente actualización: use vías o archivos distintos.

Sin carpeta seleccionada.

Cómo funciona

  1. Pulse Seleccionar carpeta… y elija (o cree) la carpeta donde vivirá el archivo, por ejemplo C:\Escuela\MATRICULA 2027. El navegador recuerda la carpeta aunque cierre y vuelva a entrar.
  2. El archivo MATRICULA_2027.xlsx se crea/actualiza al instante y cada vez que llega una matrícula nueva o cambia un estado (puede apagarse con el cuadro de arriba).
  3. Si el navegador vuelve a pedir permiso (por seguridad), vuelva a pulsar Seleccionar carpeta… o Guardar registros ahora y conceda el acceso.
  4. Si el archivo está abierto en Excel, ciérralo para que el puente/página pueda reescribirlo.
